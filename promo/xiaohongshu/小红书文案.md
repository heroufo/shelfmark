## 二、正文（主推版 · 可直接复制）

```
换了三次电子书管理软件之后，我决定自己写一个。

我的需求特别简单：几百本电子书散在各个文件夹里，
想找一本，得靠回忆文件名。
用 Excel 记书，记到第 30 本心态就崩了。
在线书库倒是好用，但我不想为了看一眼自己的书单，
先把几百本书都传上去。

所以花了不少时间，写了个叫 Shelfmark 的小工具。

它本质上就是一个 exe：
📥 扫一遍硬盘，几百本书自动进库
🖼️ 封面墙浏览，按标签 / 状态 / 星级 / 丛书随便筛
🔍 书籍信息一键补齐，出版社、年份、页数、简介都不用填
🌏 作者国籍自动标注，按文件名识别，几秒搞定
🧠 智能书架，定好规则自动归集，不用手动整理
🌐 还能一键生成只读网页，手机上翻书单

最舒服的一点是：
所有数据都在我自己的电脑里，断网能用，
不用注册，不用登录，也不会上传任何东西。

用法就三步：
1️⃣ 下载 zip（11 MB 左右）
2️⃣ 解压到任意普通文件夹
3️⃣ 双击 Shelfmark.exe，浏览器自己就打开了

不用装 Python，不用管理员权限，完全免费开源（MIT 协议）。
想要的话在评论区说一声，我把项目主页发给你～

如果你也有一堆电子书散得到处都是，欢迎拿去用～
用着有问题可以留言，我看到都会回。

#电子书 #电子书管理 #开源项目 #独立开发 #程序员日常
#效率工具 #数字书房 #书单管理 #本地软件 #Python
```

## 四、发布建议

**标签**：6–10 个最合适。上面给了 10 个，想精简就留
`#电子书 #电子书管理 #开源项目 #独立开发 #效率工具 #本地软件`。

**链接处理（重要 · 已踩坑）**：
- ❌ **图片上绝对不能出现任何网址。** 封面和「怎么用」图原来底部的 `github.com/...`
  已被小红书判定违规，现已全部去掉；步骤文案里的平台名也一并改成「项目的发布页」。
  出图脚本 `build_cards.py` 里已搜不到任何 `http` / 域名 / 平台名字样。
- ❌ 正文也**不要**写完整 URL，也不要用「GitHub 搜 xxx」这类平台名引导。
- ✅ 正确做法：正文写「评论区说一声，我把项目主页发给你」，
  再用**自己的号**在**评论区置顶**放地址；个人简介里也可以留一条。

**发布前过审自检**：
- [ ] 5 张图里搜不到 `http` / `www` / `.com` / 平台名 等任何字样
- [ ] 正文没有完整链接，没有平台名引导
- [ ] 没有二维码、微信号、手机号
- [ ] 「界面示意」标注还在（避免被当成虚假截图投诉）

**发布时间**：工作日 12:00–13:00、20:00–22:00；
周末 20:00–23:00 流量更好。

**首图**：用 `xhs_01_封面.png`。如果数据不好，可换成
`xhs_04_界面.png` 做 A/B（软件截图类首图实测点击率也高）。

**评论区自问自答**（提升互动，可选）：
- 「支持 Mac 吗？」→ 目前是 Windows 版，源码是 Python，Mac 上也能跑源码。
- 「能导入 Kindle / 微信读书的书吗？」→ 它是本地书库管理，扫的是你自己硬盘上的电子书文件。
- 「免费吗？」→ 完全免费，MIT 开源，无广告无会员。
