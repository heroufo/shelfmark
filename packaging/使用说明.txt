========================================================
  Shelfmark · 私人书库  —— 免安装版（Windows 10/11 x64）
========================================================

■ 这是什么
  本文件夹内的「Shelfmark.exe」是独立单文件程序：内置 Python 运行时与全部
  界面资源，目标电脑【无需安装 Python】、无需联网、无需管理员权限。
  管理的是「你的电脑上已有」的电子书文件（pdf / epub / mobi），本程序只
  记录它们的书名、作者、封面等信息，不会复制或移动电子书本身。

■ 怎么用
  1. 把整个文件夹解压到任意普通目录（如 D:\Shelfmark、桌面、文档）
  2. 双击「Shelfmark.exe」
  3. 稍候几秒会自动打开浏览器（地址 http://127.0.0.1:5000）
     若浏览器没自动打开，手动访问该地址即可
  4. 首次进入是空书库：点左侧「新增书籍」或「工具合集 → 批量扫描导入」，
     指向你存放电子书的文件夹，即可把藏书批量收进来
  5. 关闭程序：在任务栏托盘/任务管理器结束 Shelfmark.exe，或直接关机

■ 文件夹说明
  Shelfmark.exe    主程序（双击运行）
  使用说明.txt     本文件
  data\            书库数据（首次运行自动创建）
    library.json     你的藏书元数据（可直接备份 / 复制）
    config.json      可选配置（在线浏览站路径 site_dir、抓取开关 online_metadata）
    app.log          运行日志，出问题时看这个
  covers\          封面图片（首次运行自动创建）

  下载包里这两个文件夹是空的、正常的 —— 它们属于你的个人数据，
  只会在你自己电脑上运行时生成。

■ 换电脑 / 备份
  整个文件夹复制到新电脑即可，书库、封面、书架全部沿用。
  只想搬数据：把 data\library.json 和 covers\ 拷过去覆盖同名文件。

■ 注意
  · 请放在普通目录（如 D:\、桌面、同步盘），不要放在 C:\Program Files 等
    需要管理员权限的位置，否则无法写入书库数据。
  · 首次运行若 Windows Defender 提示「已保护你的电脑」，选「更多信息 →
    仍要运行」并添加信任即可。这是未做数字签名的单文件程序的常见误报，
    属正常现象；介意的话可自行对照 Release 页面公布的 SHA256 校验值。
  · 本程序只读写元数据：删除书籍、批量导入都不会删除或移动你磁盘上的
    电子书文件。

■ 可选：在线只读浏览站（GitHub Pages）
  「在线发布」按钮会把书库导出到静态站点目录并执行 git 提交推送。
  使用前提：本机装有 git，且已在 data\config.json 里配置站点目录，例如
      { "site_dir": "D:\\你的站点仓库路径" }
  没有配置时按钮会给出中文提示，不影响本地使用。

■ 可选：完全离线
  在 data\config.json 写入 { "online_metadata": false } 可关闭全部在线抓取
  （豆瓣元数据 / 简介），程序其余功能不受影响。

■ 从源码运行（开发者）
  项目主页 https://github.com/heroufo/shelfmark
  python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
  .venv\Scripts\python app.py        （或双击 start.bat）
  自行打包 exe：见 CONTRIBUTING.md
